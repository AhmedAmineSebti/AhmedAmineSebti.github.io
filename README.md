## 🔧 About Me

I'm an **Embedded Systems Engineer** passionate about low-level programming, microcontroller firmware, and real-time signal processing. I work close to the metal — where software meets silicon.

- 🛠️ Building custom firmware for **STM32** microcontrollers
- 📡 Designing **digital filters** (IIR/FIR) for signal processing applications
- ⚡ Interested in **bootloaders**, **RTOS**, and bare-metal C
- 🌐 Maintaining a personal portfolio at [AhmedAmineSebti.github.io](https://AhmedAmineSebti.github.io)
